# Fact Check · Mobile

HackAlem AI · Креативные индустрии. Начальный frontend сервиса подбора event-подрядчиков в Казахстане.

Стек: Expo SDK 57, React Native, JavaScript/JSX, Expo Router, NativeWind 4 / Tailwind 3, Zustand, Axios, Lucide. TypeScript в исходниках не используется.

## Установка

Node.js >=22.13, npm. Из `frontend/`:

```sh
npm ci
cp .env.example .env
```

Укажите URL backend в `.env` и согласуйте [API-контракт](docs/api-contract.md). Для физического телефона используйте LAN IP компьютера или HTTPS адрес сервера; `localhost` на телефоне указывает на телефон. Android Emulator обычно обращается к компьютеру по `10.0.2.2`. Для web backend должен разрешать CORS.

## Отдельное приложение для разработки

```sh
npm run android
# или на macOS с Xcode:
npm run ios
```

Команды генерируют нативный проект и собирают **собственное приложение Fact Check с expo-dev-client**. Expo Go не нужен. Android требует Android Studio/SDK и эмулятор или подключённый телефон. iOS требует совместимый Xcode и установленный Simulator; физическому iPhone нужна настройка подписи.

После первой установки:

```sh
npm start
```

Откройте установленный Fact Check и подключитесь к Metro. Изменения JS/JSX обновляются через Fast Refresh; изменения нативных библиотек или config plugins требуют повторной сборки.

Облачная альтернатива (потребуется ваш Expo-аккаунт и настройка EAS project):

```sh
npx eas-cli@latest build:configure
npx eas-cli@latest build --profile development --platform android
# Для iOS Simulator:
npx eas-cli@latest build --profile development-simulator --platform ios
```

Development-сборка отдельная, но использует Metro. Для демо без Metro предусмотрен `preview` профиль (Android APK):

```sh
npx eas-cli@latest build --profile preview --platform android
```

`npm run web` — дополнительный способ проверить интерфейс в браузере.

## Структура

- `src/app/` — маршруты Expo Router, JS/JSX.
- `src/components/` — поля, варианты выбора и карточки результата.
- `src/store/` — состояние формы и запроса через Zustand.
- `src/services/api.js` — Axios и адаптер API.
- `src/utils/order.js` — валидация и сериализация формы.

## Готово и что осталось

Готовы начальный экран, обязательные/дополнительные поля, проверка дат окна датасета, состояния загрузки/ошибки, три исхода ответа, вывод объяснений и флагов происхождения данных. Данные и AI-логика не дублируются во frontend. Без настройки API приложение честно сообщает, что сервис не подключён.

Следующий шаг: согласовать API и проверить живые сценарии из задания: плотная категория, редкая категория, отсутствие результата; повтор запроса; смена даты. Пока backend не подключён, эти критерии не считаются выполненными. Бронирования нет.

## Обновлённый интерфейс

Три шага: событие → подрядчик и бюджет → пожелания. Календарь позволяет выбирать даты только в окне датасета; список категорий разворачивается без потери выбора. Бюджет поддерживает форматирование и быстрые суммы. Перед отправкой доступен редактируемый бриф. На широком экране бриф расположен справа, на телефоне — в третьем шаге. Нижняя кнопка закреплена над safe area.

В выдаче отдельно оформлены загрузка, сетевая ошибка с повтором, отсутствие категории, отсутствие совпадений и 1–3 карточки. Объяснения приходят из API, детали цены раскрываются в карточке. Порядок backend не меняется. Данные формы сохраняются при переходах и ошибке в пределах запущенного приложения; сохранение после перезапуска не реализовано.

Палитра: `src/constants/theme.js` и `tailwind.config.js`; варианты выбора — `src/constants/options.js`. Иллюстрация — собственный SVG-компонент `EventArtwork.jsx`, без внешних изображений. Появление контента учитывает системную настройку уменьшения движения.

Проверки редизайна: браузер на ширинах 319, 390 и 1280 px; выбор дат и границ периода; переходы и сохранение условий; загрузка, карточки и оба пустых исхода через временный локальный тестовый API. Тестовые профили не входят в приложение и не подменяют реальный backend. JS-бандлы собираются для Android/iOS/web. Проверка на физическом устройстве и интеграция с настоящим API остаются отдельными шагами.
